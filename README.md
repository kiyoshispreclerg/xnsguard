# XisTools

Some tools to use with XiS, a [XLibre soft fork](https://github.com/kiyoshispreclerg/xserver), both made with a lot of help from AI.

### XisGuard

A lightweight external permission guardian for XiS.

### XisBack

A lightweight wallpaper tool for X11 servers.

### XisConf

A Python tool for configuring various XiS and other X11 servers' settings.
